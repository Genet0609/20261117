# 星燼學院：符文試煉

一款原創、免安裝的繁體中文 HTML5 知識問答與回合制元素戰鬥遊戲。回答題目施展咒術、掌握火水風相剋，挑戰三場試煉。

## 開始遊玩

直接在瀏覽器開啟專案根目錄的 `index.html` 即可遊玩。遊戲以原生 HTML、CSS、Canvas 與 JavaScript 製作，不需要安裝套件，也不需要網路連線或外部素材。

## 操作方式

- 按「開始試煉」進入遊戲，點選四個選項之一作答。
- 答對會施展題目指定的元素咒術；答錯時魔物會反擊。每次作答後按「繼續試煉」進入下一題。
- 火克風、風克水、水克火。答對可累積連擊與分數；擊倒魔物會恢復生命和魔力。
- 魔力不足時仍能使用威力較弱的微光彈。生命值歸零或擊退三隻魔物後，可按「再次挑戰」重新開始。
- 支援滑鼠、觸控與鍵盤 Tab / Enter 操作。

## 發布到 GitHub Pages

1. 將此分支的變更推送到 GitHub。
2. 開啟儲存庫 **Settings → Pages**。
3. 在 **Build and deployment** 選擇 **Deploy from a branch**。
4. 選擇要發布的分支及 `/(root)` 資料夾，按 **Save**。
5. 等待 Pages 部署完成後，從 Pages 設定頁提供的網址遊玩。

遊戲入口是根目錄 `index.html`，可由 GitHub Pages 直接提供靜態檔案，無需建置流程。
