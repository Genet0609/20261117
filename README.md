# 霧境前線｜星垣守望

一款以原創世界觀與 Canvas/CSS 繪製的繁體中文即時戰略生存遊戲。遊戲只有一個 HTML 檔案，不需要安裝套件、建置工具或外部素材。

## 開始遊玩

直接以現代瀏覽器開啟根目錄的 `index.html` 即可。也可以用任何靜態檔案伺服器提供此資料夾。

## 遊戲目標與操作

- 採集木料與星晶，建造守望軍營、脈衝塔與星晶中繼站。
- 在軍營訓練星衛，守住星垣基地，摧毀地圖北方的掠霧核心即可獲勝。
- 點選拓荒者，再以滑鼠右鍵點擊木林／星晶礦脈採集；右鍵點擊地面移動、點擊敵人攻擊。觸控裝置可點選單位後點選目標。
- 選取基地或拓荒者以開啟建造選項。選擇建築後，在地圖空地點擊放置；按 `Esc` 可取消。
- 右上角可切換遊戲速度或重新部署。星垣基地被摧毀時遠征失敗。

## GitHub Pages 發布

1. 將此分支推送到 GitHub。
2. 在儲存庫 **Settings → Pages** 中，將發布來源設為 **Deploy from a branch**。
3. 選擇此分支與根目錄 (`/`) 後儲存。待 Pages 部署完成後，即可使用提供的網址遊玩。

遊戲資源由內嵌 JavaScript Canvas 和 CSS 即時繪製，沒有外部相依或素材請求。
